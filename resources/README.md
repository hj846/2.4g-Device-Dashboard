# 本机驱动原始设备图库

打开 `index.html` 可离线浏览，搜索型号或配色；点击图片查看原始文件。

- `mchose/K87 V3/`：从已安装 M HUB 的本地 Chromium 缓存提取 6 款透明 PNG，尺寸以 manifest 为准。包含黑、白、白蓝、蓝、蜜桃粉、绿；每张图保留缓存来源、原始官方 URL 和 SHA-256。`extract-mchose.cjs` 可重新提取当前缓存。未发现其他型号的已缓存展示图。

- `rapoo/`：从本机 AHUB 的打包 JavaScript 中解析“型号/原始文件名 → 打包图片”的映射，恢复 107 个型号目录、619 张图片。`thumb_` 是展示缩略图，`func_` 是驱动功能页图片，部分包含正反两面。
- `logitech/`：G HUB 自带的 116 张具名产品图，包含鼠标及其他外设。保留驱动型号命名，不推测未验证的地区型号别名。
- `aula/F75/keyimg.png`：狼蛛 F75 驱动的键盘布局原图。
- 雷蛇：扫描本机常见安装目录、迁移目录及其他磁盘的安装目录，找到安装器残留、应用图标，未找到可用的设备产品图，因此没有用安装器图标冒充鼠标图片。

`manifest.json` 记录每张图片的来源、型号、SHA-256、大小及 PNG 尺寸。资源按原始字节保存；重复图片在本资源目录内部使用硬链接节省空间，与已安装驱动文件没有硬链接关系。

`extract-local.cjs` 是本次提取脚本，仅读取驱动文件、解析资源映射，不执行驱动中的 JavaScript，也不修改已安装软件。脚本的安装路径和版本对应本次机器状态。

这些图片来自厂商驱动，并非 AI 生成。素材权利仍归原权利方。已通过 `prepare-app-images.cjs` 将展示图接入应用，原始图库继续保留。应用优先精确匹配型号；未匹配的设备显示对应类别的通用写实示意图，并支持用户点击展示图上传真实图片。
